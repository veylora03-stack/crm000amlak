# وایرفریم‌ها — CRM تخصصی املاک

این سند ساختار کلی صفحات را به‌صورت Wireframe متنی تعریف می‌کند. هدف، مشخص بودن چیدمان، هدر، Sidebar، محتوا، اقدامات، حالت خالی و حالت خطا قبل از پیاده‌سازی UI است.

---

## الگوی کلی Layout

### دسکتاپ
- Sidebar سمت راست، عرض ثابت 264px
- Topbar ثابت در بالا، ارتفاع 64px
- محتوای اصلی قابل اسکرول
- Padding استاندارد محتوا: 24px
- حداکثر عرض محتوا برای فرم‌ها و صفحات مدیریتی: 1440px
- Toastها در پایین یا گوشه مناسب نمایش داده شوند
- Modalها روی کل صفحه Overlay داشته باشند

### موبایل
- Sidebar به‌صورت کشویی از سمت راست
- Topbar شامل منوی همبرگری، جستجو و نوتیفیکیشن
- محتوا تک‌ستونه
- جداول به کارت یا Scroll افقی تبدیل شوند
- Kanban دارای Scroll افقی باشد

## جمع‌بندی Wireframe

| صفحه | Layout اصلی | Actions کلیدی | حالت خالی | حالت خطا |
|---|---|---|---|---|
| Login | AuthLayout | ورود | فرم خالی | Validation/Server Error |
| Dashboard | AppLayout | فیلتر، Drill-down | نمودار خالی | Retry |
| Clients | AppLayout + Table | افزودن، ویرایش، Export | لیست خالی | Retry/Validation |
| Client Detail | AppLayout + Tabs | تعامل، Deal، تخصیص | Timeline خالی | Not Found/No Permission |
| Properties | AppLayout + Table | افزودن، ویرایش، Export | لیست خالی | Retry/Validation |
| Property Detail | AppLayout + Gallery | ویرایش، انتشار، آرشیو | گالری خالی | Not Found/No Permission |
| Pipeline | AppLayout + Kanban | Drag & Drop، ایجاد Deal | Stage خالی | Undo/Retry |
| Deals | AppLayout + Table | ایجاد، ویرایش، برد/باخت | لیست خالی | Retry/Validation |
| Tasks | AppLayout + Views | ایجاد، تکمیل، فیلتر | وظیفه خالی | Retry/Validation |
| Reports | AppLayout + Filters | Export، فیلتر | داده خالی | Export Error |
| Notifications | AppLayout | خوانده‌شده | نوتیفیکیشن خالی | Retry |
| Settings | AppLayout + Tabs | ذخیره، مدیریت مقادیر | لیست خالی | No Permission/Validation |
| Profile | AppLayout | ویرایش، تغییر رمز | فرم خالی | Validation |
| Users | AppLayout + Table | ایجاد، نقش، فعال/غیرفعال | کاربر خالی | No Permission/Validation |
