# آیکون‌ها — CRM تخصصی املاک

این سند سیستم آیکون‌ها را تعریف می‌کند. همه آیکون‌ها باید فارسی‌نام، قابل دسترس، سازگار با RTL، دارای اندازه استاندارد و قابل استفاده در Light/Dark Mode باشند.

---

## 1. اصول کلی

- آیکون‌ها باید ساده، واضح و یکدست باشند.
- از افزودن کتابخانه آیکون سنگین خارج از وابستگی‌های مجاز پرهیز شود.
- پیاده‌سازی پیشنهادی: SVGهای inline یا کامپوننت‌های آیکون محلی.
- همه آیکون‌ها باید از `currentColor` استفاده کنند تا رنگ را از متن یا کلاس بگیرند.
- آیکون‌ها نباید متن اصلی را جایگزین شوند.
- برای عناصر تعاملی بدون متن، باید `aria-label` فارسی تعریف شود.
- آیکون‌های تزئینی باید `aria-hidden="true"` داشته باشند.
- آیکون‌ها باید در Dark Mode بدون تغییر ساختار فقط رنگ عوض کنند.
- در RTL، آیکون‌های جهت‌دار باید معکوس شوند.

---

## 2. اندازه‌ها

| اندازه | کاربرد |
|---:|---|
| 16px | متن‌های کوچک، Badge، Caption، دکمه‌های خیلی کوچک |
| 20px | حالت پیش‌فرض برای دکمه‌ها، فرم‌ها، جدول‌ها و Dropdown |
| 24px | منوی اصلی، Topbar، KPI Cards، Empty State |

### قواعد اندازه
- آیکون منوی Sidebar باید 20px یا 24px باشد.
- آیکون دکمه‌های معمولی باید 20px باشد.
- آیکون داخل Input باید 16px یا 20px باشد.
- آیکون Toast و Alert باید 20px باشد.
- آیکون Empty State می‌تواند 40px یا بزرگ‌تر باشد، اما از همان ساختار آیکون‌ها پیروی کند.
- نباید آیکون را با تغییر width/height غیراستاندارد کشیده یا فشرده کرد.

---

## 3. حالت‌های Outline و Solid

| حالت | کاربرد |
|---|---|
| Outline | حالت پیش‌فرض منوها، دکمه‌های غیرفعال، جدول‌ها و فرم‌ها |
| Solid | آیتم فعال منو، Tab فعال، وضعیت انتخاب‌شده، دکمه‌های مهم در صورت نیاز |

### قواعد
- منوی Sidebar در حالت عادی از Outline استفاده کند.
- منوی Sidebar در حالت فعال از Solid استفاده کند.
- دکمه‌های خطرناک می‌توانند آیکون Outline با رنگ danger داشته باشند.
- Badge و Status آیکون‌ها باید با رنگ وضعیت همراه باشند.
- تغییر Outline به Solid نباید باعث تغییر اندازه شود.

---

## 4. ساختار فنی آیکون‌ها

### مشخصات SVG
- viewBox: `0 0 24 24`
- fill: `currentColor` برای Solid
- stroke: `currentColor` برای Outline
- stroke-width پیشنهادی: `1.5` یا `2`
- stroke-linecap: `round`
- stroke-linejoin: `round`
- بدون رنگ hardcoded
- بدون سایه داخلی یا gradient غیرضروری

### رفتار در کامپوننت
- رنگ آیکون از `text-*` یا کلاس semantic گرفته شود.
- در حالت disabled، آیکون باید `text-disabled` شود.
- در حالت hover، آیکون باید همراه متن تغییر رنگ دهد.
- در حالت focus، آیکون نباید focus ring جداگانه داشته باشد؛ فوکوس روی عنصر تعاملی باشد.

## 5. نام‌گذاری آیکون‌ها

### الگو
`icon-<category>-<name>-<variant>`

### مثال‌ها
- `icon-nav-dashboard-outline`
- `icon-nav-dashboard-solid`
- `icon-action-edit-outline`
- `icon-status-success-solid`
- `icon-file-image-outline`

### قواعد
- نام‌ها باید کوچک و با خط فاصله باشند.
- نام‌ها باید معنایی باشند.
- نام‌های فارسی فقط برای Label و aria-label استفاده شوند.
- در کد، نام انگلیسی کوتاه و ثابت داشته باشند.

## 16. دسترسی‌پذیری آیکون‌ها

### آیکون تزئینی
- اگر آیکون کنار متن است، باید `aria-hidden="true"` داشته باشد.
- متن باید مسئول انتقال معنا باشد.

### آیکون تعاملی بدون متن
- باید `role="button"` یا عنصر button داشته باشد.
- باید `aria-label` فارسی داشته باشد.
- باید با کیبورد قابل فعال‌سازی باشد.
- باید focus visible داشته باشد.

### نمونه aria-label
- «بستن»
- «باز کردن منو»
- «جستجو»
- «ویرایش مشتری»
- «حذف ملک»
- «نمایش رمز عبور»
- «علامت‌گذاری به‌عنوان خوانده‌شده»

### قواعد
- هیچ دکمه آیکونی نباید بدون aria-label باشد.
- Tooltip نباید جایگزین aria-label شود.
- آیکون‌های وضعیت باید با متن یا Badge همراه باشند.
- کنتراست آیکون‌های ضروری باید حداقل AA باشد.

## 17. آیکون‌ها در کامپوننت‌ها

### Button
- آیکون قبل از متن در RTL سمت راست متن قرار گیرد.
- فاصله آیکون تا متن: 8px
- اندازه آیکون: 20px
- دکمه Icon-only باید aria-label داشته باشد.

### Input
- آیکون داخل Input باید خاکستری باشد.
- در RTL، آیکون ابتدایی در سمت راست و آیکون انتهایی در سمت چپ قرار گیرد.
- هدف لمسی آیکون انتهایی باید حداقل 44px باشد.

### Table
- آیکون Sort باید 16px باشد.
- آیکون Row Actions باید داخل Dropdown باشد.
- آیکون وضعیت باید با Badge استفاده شود.

### Modal / Drawer
- آیکون بستن باید 20px یا 24px باشد.
- دکمه بستن باید aria-label «بستن» داشته باشد.
- در RTL، دکمه بستن معمولاً در سمت چپ هدر قرار گیرد.

### Toast / Alert
- آیکون باید در ابتدای پیام باشد.
- اندازه آیکون: 20px
- رنگ آیکون باید با نوع پیام هماهنگ باشد.

### Empty / Error State
- آیکون اصلی می‌تواند بزرگ‌تر باشد.
- باید با عنوان و توضیح فارسی همراه باشد.
- دکمه CTA باید آیکون مناسب داشته باشد.

## 18. Dark Mode و آیکون‌ها

- آیکون‌ها باید از `currentColor` استفاده کنند.

- آیکون‌های غیرفعال باید کم‌رنگ باشند.
- آیکون‌های وضعیت باید در هر دو حالت خوانا باشند.
- نباید برای Dark Mode نسخه جداگانه SVG ساخت، مگر برای آیکون‌های خیلی خاص.
