# تایپوگرافی — CRM تخصصی املاک

این سند قواعد تایپوگرافی فارسی، سلسله‌مراتب متون، اندازه‌ها، وزن‌ها و رفتارهای مرتبط با RTL و Dark Mode را تعریف می‌کند.

---

## 1. فونت اصلی

### فونت فارسی
- فونت اصلی: Vazirmatn
- فونت جایگزین: Tahoma
- فونت سیستمی برای fallback: sans-serif

### Font Stack پیشنهادی
`"Vazirmatn", "Tahoma", "Segoe UI", sans-serif`

### قواعد فونت
- همه صفحات باید با فونت فارسی نمایش داده شوند.
- استفاده از فونت‌های انگلیسی برای متن فارسی ممنوع است.
- برای اعداد و تاریخ‌ها از فرمت فارسی با Intl استفاده شود.
- فونت نباید در Dark Mode تغییر کند.
- فونت باید در RTL کاملاً خوانا باشد.

---

## 2. اندازه‌های فونت

| توکن | اندازه | Line Height | کاربرد |
|---|---:|---:|---|
| `text-xs` | 12px | 18px | متن بسیار کوچک، راهنما، Badge |
| `text-sm` | 14px | 20px | متن جدول، Label، فرم‌ها |
| `text-base` | 16px | 24px | متن اصلی، پاراگراف |
| `text-lg` | 18px | 28px | زیرعنوان، کارت‌ها |
| `text-xl` | 20px | 28px | عنوان بخش |
| `text-2xl` | 24px | 32px | عنوان صفحه |
| `text-3xl` | 30px | 36px | عنوان بزرگ، KPI مهم |

### قواعد اندازه‌ها
- متن اصلی باید حداقل `text-base` باشد.
- متن جدول‌ها می‌تواند `text-sm` باشد.
- متن Labelها `text-sm` باشد.
- متن راهنما و Captionها `text-xs` باشد.
- در موبایل نباید متن از 14px کوچک‌تر شود.

---

## 3. وزن‌های فونت

| وزن | مقدار عددی | کاربرد |
|---|---:|---|
| Regular | 400 | متن بدنه |
| Medium | 500 | Label، متن ثانویه مهم |
| SemiBold | 600 | عنوان‌ها، دکمه‌ها، Tab فعال |
| Bold | 700 | تأکید قوی، KPI، عنوان صفحه |

### قواعد وزن‌ها
- از وزن کمتر از 400 برای متن فارسی استفاده نشود.
- عنوان‌ها باید حداقل SemiBold باشند.
- دکمه‌ها باید SemiBold باشند.
- Bold فقط برای تأکید خاص و KPIها استفاده شود.
- استفاده زیاد از Bold باعث شلوغی می‌شود.

---

## 4. سلسله‌مراتب عنوان‌ها

| سطح | سایز | وزن | کاربرد |
|---|---|---|---|
| H1 | `text-2xl` یا `text-3xl` | Bold | عنوان اصلی صفحه |
| H2 | `text-xl` یا `text-2xl` | SemiBold | عنوان بخش |
| H3 | `text-lg` | SemiBold | عنوان کارت یا بلوک |
| H4 | `text-base` | SemiBold | عنوان فرعی |
| Body | `text-base` | Regular | متن اصلی |
| Caption | `text-xs` یا `text-sm` | Regular | متن کمکی |

### قواعد سلسله‌مراتب
- هر صفحه فقط یک H1 داشته باشد.
- عنوان صفحه در PageHeader باید H1 باشد.
- عنوان کارت‌ها معمولاً H3 باشد.
- فاصله بین عنوان و محتوا باید حداقل `space-2` باشد.

---

## 5. ارتفاع خطوط — Line Height

| توکن | مقدار | کاربرد |
|---|---:|---|
| `leading-tight` | 1.25 | عنوان‌ها |
| `leading-normal` | 1.5 | متن بدنه |
| `leading-relaxed` | 1.75 | پاراگراف‌های طولانی |

### قواعد
- عنوان‌ها باید `leading-tight` باشند.
- متن بدنه باید `leading-normal` باشد.
- توضیحات طولانی در فرم‌ها یا Timeline می‌توانند `leading-relaxed` باشند.
- برای متن فارسی، line-height کم باعث کاهش خوانایی می‌شود.

---

## 6. فاصله بین کلمات و حروف

- `letter-spacing` برای متن فارسی ممنوع است.
- `word-spacing` فقط در صورت نیاز بسیار کم استفاده شود.
- متن‌های فارسی باید به‌صورت طبیعی break شوند.
- از `text-justify` برای متن‌های کوتاه استفاده نشود.
- برای متن‌های طولانی از `text-right` و `leading-normal` استفاده شود.

## 7. تایپوگرافی در فرم‌ها

| عنصر | سایز | وزن | رنگ |
|---|---|---|---|
| Label | `text-sm` | Medium | متن اصلی |
| Input Text | `text-base` | Regular | متن اصلی |
| Placeholder | `text-sm` | Regular | متن کم‌رنگ |
| Help Text | `text-xs` | Regular | متن ثانویه |
| Error Message | `text-xs` | Medium | Danger |
| Success Message | `text-xs` | Medium | Success |

### قواعد فرم‌ها
- Placeholder نباید جایگزین Label شود.
- پیام خطا باید زیر فیلد نمایش داده شود.
- پیام خطا باید فارسی و مشخص باشد.
- Labelها باید راست‌چین باشند.
- در موبایل، Inputها باید `text-base` باشند تا زوم ناخواسته ایجاد نشود.

| Header | `text-sm` | SemiBold |
| Cell | `text-sm` | Regular |
| Numeric Cell | `text-sm` | Medium |
| Empty State | `text-sm` | Regular |

### قواعد جدول‌ها
- Header جدول باید از بدنه متمایز باشد.
- اعداد باید راست‌به‌چپ و با فرمت فارسی نمایش داده شوند.
- مبلغ‌ها باید جداکننده هزارگان داشته باشند.
- تاریخ‌ها باید شمسی نمایش داده شوند.
- متن طولانی در سلول باید با Ellipsis یا Tooltip مدیریت شود.

| نوع دکمه | سایز | وزن |
|---|---|---|
| دکمه اصلی | `text-base` | SemiBold |

- متن دکمه نباید بیش از دو کلمه اصلی باشد.
- دکمه‌ها باید در حالت disabled وضوح کافی داشته باشند.
- دکمه‌های خطرناک باید رنگ و متن واضح داشته باشند.

- عنوان KPI باید کوتاه و قابل فهم باشد.
- اعداد باید فارسی و با فرمت مناسب نمایش داده شوند.
- نمودارها باید برچسب‌های خوانا داشته باشند.

---

## 11. تایپوگرافی در Dark Mode

- اندازه‌ها و وزن‌ها در Dark Mode تغییر نکنند.
- فقط رنگ متن‌ها تغییر کند.
- متن اصلی نباید در Dark Mode کاملاً سفید خالص باشد.
- متن ثانویه باید کنتراست کافی داشته باشد.
- Placeholder باید کم‌رنگ‌تر از متن اصلی باشد.
- پیام خطا باید در هر دو حالت خوانا باشد.

---

## 12. تایپوگرافی در RTL

- جهت متن باید راست‌به‌چپ باشد.
- Alignment پیش‌فرض متن‌ها `text-right` باشد.
- آیکون‌ها در کنار متن باید فاصله مناسب داشته باشند.
- در Inputها، caret باید با جهت متن سازگار باشد.
- برای فیلدهای موبایل، ایمیل و کد لاتین می‌توان `dir="ltr"` با alignment مناسب استفاده کرد.
- متن فارسی با اعداد فارسی باید در کل محصول یکسان باشد.

---

## 13. نمایش اعداد و تاریخ

- تاریخ‌ها باید شمسی نمایش داده شوند.
- فرمت تاریخ با Intl API انجام شود.
- اعداد باید با جداکننده هزارگان فارسی نمایش داده شوند.
- مبالغ باید با واحد ریال یا تومان طبق تنظیمات نمایش داده شوند.
- در ورودی‌ها، ذخیره مقدار به‌صورت عددی و بدون جداکننده باشد.
- در خروجی‌ها، نمایش با فرمت فارسی باشد.

---

## 14. قواعد دسترسی‌پذیری تایپوگرافی

- حداقل کنتراست متن باید AA باشد.
- متن اصلی نباید کوچک‌تر از 14px باشد.
- Placeholder نباید تنها وسیله انتقال اطلاعات باشد.
- focus state باید واضح باشد.
- لینک‌ها باید با رنگ و underline یا نشانه قابل تشخیص باشند.
- متن‌های خطا باید با نقش و رنگ قابل تشخیص باشند.
